## Introduction

This chart bootstraps an agent platform cluster.
This is a minimal set of components that are required to run an agent platform cluster.

## Prerequisites

- Kubernetes 1.28+ with Beta APIs enabled

## A Quick Note on Versioning

The version references _only_ the revision of the chart itself. The `appVersion` field in
`Chart.yaml` conveys information regarding the revision of ZAP that the chart provides.
